jinflow Quick Start

This guide gets you from zero to exploring in 5 minutes. For detailed documentation, see the User Guides.

What is jinflow?

Section titled “What is jinflow?”

jinflow is a declarative analytical engine. You declare signals, theses, and verdicts; jinflow compiles them to SQL, builds a DuckDB knowledge store (KLS), and serves it through JinDesk web app.

Domain knowledge lives in packs (e.g. a operations pack, a winemaking pack, a logistics pack). The engine handles compilation, validation, and exploration.

Install

Section titled “Install”

Download the latest release for your platform from jinflow.io. The package is self-contained — no Python, Node, or dbt installation required.

5-Minute Walkthrough

Section titled “5-Minute Walkthrough”

1. Configure

Section titled “1. Configure”

See Setup Guide for full resolution order and DLZ configuration.

2. Initialize a tenant

Section titled “2. Initialize a tenant”

This creates ~/jinflow-live/hrcentral/vai/ with afs/, raw/, build/, store/ directories.

See Tenants Guide for pack-qualified IDs, cloning, and multi-pack.

3. Build

Section titled “3. Build”

This runs the full pipeline: validate CSVs, compile instruments, run dbt (Bronze -> Silver -> Gold -> Signals -> Theses -> Verdicts), generate reports, and stamp the KLS.

See Make Guide for flags (--sync, --extract, --clean, --snapshot).

4. Explore

Section titled “4. Explore”

Opens JinDesk at localhost:4000. Browse theses, findings, dimensions, taxonomies, SMEbits, and reports.

See JinDesk Guide for pages, keyboard shortcuts, JumpBar, and saved views.

5. Iterate

Section titled “5. Iterate”

See Instruments Guide for all instrument types.

Key Concepts

Section titled “Key Concepts”
TermMeaning
PackDomain-specific analytics kit (e.g. Millesime, Alptrack)
TenantOne client/site. Pack-qualified: hrcentral.vai
KLSKnowledge Store — the DuckDB file you build and explore
AFSArtifact Store — the analytical framework (git-backed)
OPSSystem Information Store — mutable user state (notebooks, saved views)
DLZData Landing Zone — where raw data arrives
SnapshotImmutable, frozen copy of a KLS
